## R1 — layout · redesign

**Diagnosis (from fingerprint):** `.features` is the three-equal-tile pattern (`flex: 1` × 3, identical padding) under a centered gradient hero — the canonical feature-tile-grid tell. Everything is centered with no focal point; the hero's job (lead) and the features' job (proof) have no visual tension between them. `fingerprint.json → antislop_hints: gradient present (check if hero)` confirmed: hero IS a gradient.

**The move:** Replace the three equal tiles with an asymmetric two-column proof layout — left column: one large capability (real-time data) as a deep panel with a mini live-chart motif; right column: stacked, alternating-alignment entries for security and speed. Kill the centered hero stack: left-align the hero, put the product screenshot (the placeholder chart) as the focal point right of the copy, headline left. This gives the page one eye-path instead of three identical boxes.

**Evidence:**
- card: `linear` — `library/cards/linear/screenshot-desktop.png`; tokens: light neutral `#f7f8f8` bg, Inter Variable + Berkeley Mono, spacing scale 1/4/7/8/11px. Linear's landing = left-aligned hero with product UI as focal point, dense-but-calm proof sections.
- card: `stripe` — `library/cards/stripe/screenshot-desktop.png`; tokens: 8px spacing scale, sohne-var, radii 4/6px. Stripe's proof sections alternate copy/image asymmetrically instead of tiling.

**Effort:** redesign · **Risk:** hero copy loses prominence if the screenshot isn't strong; mitigate by keeping the headline at 40px+ and letting the chart be the eye-path.

## R2 — color · medium

**Diagnosis (from fingerprint):** `#6366f1` (indigo-600 class) as CTA + nav logo + stat numbers, with a `#6366f1→#a855f7` hero gradient — the generic-tech-hue tell, and it's doing 4 jobs (brand, CTA, link, accent) with no hierarchy. No semantic roles (bg/surface/border/text/accent), no theme tokens — `themes: {count: 1, names: [light]}`.

**The move:** Build a 60-30-10 token system: warm-neutral dominant (`--bg #FAFAF9`, `--surface #F5F5F4`, `--border #E7E5E4`, `--text #1C1917`, `--text-muted #78716C` — stone family, not slate), one statement hue reserved for CTA + primary actions only (`--accent`, pick a pulse-appropriate green or teal — NOT another indigo), stat numbers demoted to text color. Add a dark theme via `data-theme="dark"` (stone-900 bg, stone-100 text) so the toggle exists from day one. Verify 4.5:1 body contrast + deuteranopia check.

**Evidence:**
- card: `anthropic` — `library/cards/anthropic/screenshot-desktop.png`; tokens: warm-neutral dark `#141413` dominant (518 occurrences), Anthropic Sans/Serif/Mono, spacing 2/4/5/8/12px. Proof that warm neutrals carry an entire brand with one restrained accent.
- card: `monzo` — `library/cards/monzo/screenshot-desktop.png`; coral statement accent on neutral, exactly the "one hue for CTA" pattern.

**Effort:** medium · **Risk:** brand-loyal users may miss the indigo; mitigate by keeping the gradient ONLY on the hero (it becomes the accent rail, not the palette).

## R3 — motion · quick

**Diagnosis (from fingerprint):** `.feature { transition: transform 0.3s cubic-bezier(0.34, 1.56, 0.64, 1) }` — the bounce-easing tell (1.56 overshoot), plus that's the ONLY interaction: `interactions: {hover:1, transition:1, active:0, focus:0, keyframes: none}`. No focus-visible ring, no active state, no reduced-motion handling, no entrance animation.

**The move:** Replace bounce with ease-out: `transition: transform 0.18s ease-out, box-shadow 0.18s ease-out`. Add `:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px }` on nav links + CTA. Add a 120ms hover-lift (translateY(-2px) + soft shadow) on cards — smaller, calmer. Wrap all motion in `@media (prefers-reduced-motion: reduce) { * { transition: none !important; animation: none !important } }`. Optionally a 300ms ease-out fade-up on hero load.

**Evidence:**
- card: `framer` — `library/cards/framer/screenshot-desktop.png`; motion-led marketing with restrained easing (motion primitives from ui-component-sourcing skill: 150–250ms ease-out entrances, exits at ~70% duration).
- card: `linear` — 120ms micro-interactions on dense UI, no bounce anywhere.

**Effort:** quick · **Risk:** near-zero; pure CSS, no layout change.
