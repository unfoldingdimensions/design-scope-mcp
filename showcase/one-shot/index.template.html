03 CONNECTION

Ten tools, one library

An MCP server with 10 tools — stdio or streamable HTTP, both supported by the same server. The register on this sheet was produced by four of them.

toolwhat it returns
pinghealth: ok + card count, or startup problems
style_searchranked cards — natural language: “funky”, “editorial but not brutalist”, “warm minimal”
style_filterstructured filter: hue / brightness / saturation / corners / flatness / type mood
card_getfull card: fingerprint + semantic + annotation + behaviors + asset paths
card_compareborrow candidates — a card's fingerprint vs your project's
theme_borrowa card's palette: token remap + contrast-guarded CSS (WCAG AA)
get_page_structureNEWthe band contract for a one-shot page — declared bands + mechanism budget
capturea website becomes a card — async job, never blocks
capture_statusqueued / running / done / failed
recommend_historythe iteration chain for a project (manifest.json)

08 START

One-shot your own sheet

Two commands: prepare runs the tools and writes the receipt; grade measures the result and keeps the ledger row. Compose the page in between — that part is yours.

→ python scripts/one_shot.py prepare --brief "your page" --direction "your direction" decisions
→ python scripts/one_shot.py grade --label "R1 one-shot" grading
→ claude mcp add design-scope -- python "<repo>/library/mcp_server.py" register
