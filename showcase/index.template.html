02 BASIS

The corpus

204 pages measured. Every one fingerprinted, motion-passed, and annotated with why it works. 201 independently reviewed by a vision pass. 202 indexed for natural-language search. None of it leaves your disk.

—pages
Captured
Fingerprinted, screenshot, motion-passed — each a full card in library/cards/.
—reviewed
Vision-reviewed
A vision pass wrote the why it works annotation on each card's card.md.
—indexed
Style-indexed
Vectorised into style-index.json — searchable in natural language.
—dark
Dark-themed
Cards whose semantic.json ships a full dark palette, ready to borrow.

Motion-evidenced
Recorded card-motion.webm + behaviors.md: what moves, when, and the easing.
11tools
Local-first

03 CONNECTION

Point your agent at one library

An MCP server with 11 tools — stdio or streamable HTTP, both supported by the same server. Register it once and the corpus is one tool call away.

toolwhat it returns
pinghealth: ok + card count, or startup problems
style_searchranked cards — natural language: “funky”, “editorial but not brutalist”, “warm minimal”
style_filterstructured filter: hue / brightness / saturation / corners / flatness / type mood
card_getfull card: fingerprint + semantic + annotation + behaviors + asset paths
card_compareborrow candidates — a card's fingerprint vs your project's
theme_borrowa card's palette: token remap + contrast-guarded CSS (WCAG AA)
get_page_structurethe band contract for a one-shot page — declared bands + mechanism budget
capturea website becomes a card — async job, never blocks
capture_statusqueued / running / done / failed
recommend_historythe iteration chain for a project (manifest.json)

08 START

Run it on your machine

One server, two transports, eleven tools. The library is a folder; point the server at yours with DESIGN_SCOPE_LIBRARY.

→ python library/mcp_server.py stdio · recommended
→ cd library && uvicorn mcp_server:app --host 127.0.0.1 --port 8232 streamable http
→ claude mcp add design-scope -- python "<repo>/library/mcp_server.py" register
